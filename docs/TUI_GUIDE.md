# TUI 操作ガイド (Terminal User Interface Guide)

`agent-eval` は、ターミナル上で直感的に操作できるテキストUI (TUI) を備えています。
エンジニア・非エンジニアを問わず、キーボード操作のみで評価の実行、Trace の時系列分析、Real Agent 記録の取込、MCP 接続設定が行えます。

---

## 1. TUI の起動

引数なしでコマンドを実行すると、自動的に TUI が全画面で起動します。

```text
agent-eval
```

---

## 2. 基本キー操作

| キー | 動作 |
| --- | --- |
| `↑` / `↓` (または `k` / `j`) | カーソル移動・項目の選択 |
| `Enter` | 決定・選択項目の実行・サブ画面への遷移 |
| `Esc` / `b` | 前の画面に戻る |
| `q` | TUI を終了する (確認後) |
| `r` | 画面の再読み込み・最新情報への更新 |
| `d` | 評価実行画面で dry-run モードの切り替え |

---

## 3. 画面構成と機能一覧

### ホーム画面 (Home)
8 つの主要機能へ直接遷移できます。
1. **新しい評価を開始**: ベンチマーク一覧から評価対象を選択し、実行します。
2. **評価結果を見る**: 過去の実行履歴 (Run ID, ステータス, 成功率, コスト, レイテンシ) を一覧表示します。
3. **Agent Trace を見る**: 選択した実行の時系列イベント（プロンプト、ツール呼出、ファイル編集、思考過程）を再生・検査します。
4. **Real Agent 記録を取り込む**: Codex や OpenCode が出力した `.jsonl` トランスクリプトを取り込み、評価 DB へ登録します。
5. **benchmark を管理する**: 登録されている評価シナリオの確認や詳細閲覧を行います。
6. **MCP 接続を設定する**: Codex 等の MCP Host へ Agent Eval Engine を登録・設定します。
7. **設定・診断**: Docker、DB、ストレージの状態診断 (`agent-eval doctor` 相当) を行います。
8. **ヘルプ**: 操作説明やドキュメントリンクを表示します。

---

### 初回設定ウィザード画面 (Setup Wizard)
未初期化の環境で初回起動した場合、またはメニューから起動された場合に案内されます。
- Docker の稼働状態を自動チェック
- 保存先ディレクトリの作成確認
- データベースの初期化と migration
- サンプル benchmark による初期動作確認 (dry-run)

---

### 評価実行・結果画面 (Evaluation & Runs)
- 評価実行中はプログレスバーと進捗状況（現在ステップ、ツール呼出回数、経過時間）が表示されます。
- 実行完了後は総合スコア、メトリクス、ツール呼出の成否、コストが表形式で表示されます。

---

### Trace 検査画面 (Trace Inspector)
特定の Run におけるイベント履歴を 1 ステップずつ追跡できます。
- **User Prompt**: ユーザーから Agent への指示内容
- **LLM Reasoning**: Agent の思考・推論ステップ
- **Tool Call / Response**: 実行されたツール名、引数、戻り値
- **File Changes**: 作成・編集された差分情報

---

### Real Agent 記録取込画面 (Trace Import Form)
Codex, OpenCode, Antigravity などの外部コーディングエージェントのログファイル (`.jsonl`) パスを入力して取り込みます。
- リアルタイムで JSONL の構造・イベント順序・秘密情報の有無を検証
- 不正な形式や秘密情報が含まれる場合は行番号と具体的な原因を表示
- 正常取込完了後は直ちに Trace 検査画面へジャンプ可能

---

### MCP 設定画面 (MCP Client Setup)
- Codex 接続コマンド (`codex mcp add agent-eval -- ...`) の生成・実行
- OpenCode / Antigravity 向け設定スニペットの表示
- MCP Server の稼働状況・待機ポートの確認

---

## 4. ターミナルサイズの適応性

TUI はターミナルサイズ（標準 80x24、広画面 120x30、小型端末）に応じて自動的にレイアウトを調整します。
- 画面幅が狭い場合: 補足説明や詳細カラムを自動省略し、重要情報（ID、ステータス、選択カーソル）を崩さず表示します。
- 画面幅が広い場合: 実行メトリクスや詳細パラメータを横並びの 2 カラム形式でリッチに表示します。
