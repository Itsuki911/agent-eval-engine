# セキュリティとプライバシーポリシー (Security & Privacy Policy)

Agent Eval Engine は、AI コーディングエージェントの安全な検証・評価を行うために、強固なプライバシー保護と機密情報管理方針を採用しています。

---

## 1. ローカル実行とデータ主権

- **完全ローカル優先**: データベース、評価ベンチマーク、トレースログ、設定ファイルはすべて利用者の端末ローカルに保存されます。
- **ゼロテレメトリ**: 利用統計、端末情報、エラー追跡などの外部テレメトリ送信コードは一切存在しません。

---

## 2. 機密情報の排除とサニタイズ原則

本システムでは、不用意な機密情報の漏洩を防ぐため以下の仕組みを徹底しています。

1. **機密情報のログ遮断**:
   - `OPENROUTER_API_KEY`、トークン、パスワード、認証ヘッダー、Cookie 等は、画面表示、実行ログ、診断レポート (`agent-eval doctor`)、Release asset に出力されません。
2. **Real Agent トレースのバリデーション拒絶**:
   - `import-trace` や `validate-trace` の処理時、キー名や値に `api_key` や `Authorization` などの機密文字列が含まれている JSONL ファイルは即座に拒否され、DB に保存されません。
3. **ローカル絶対パスの難読化**:
   - 診断出力やレポートにおいて、ユーザー名を含むフルパスは相対パスまたは環境変数プレースホルダー (`%LOCALAPPDATA%` 等) に置き換えられます。

---

## 3. サンドボックス実行の安全性

- **Docker コンテナ隔離**: 評価対象のコード実行は独立したコンテナ内で行われ、ホスト端末のファイルシステムへの直接の破壊操作を防ぎます。
- **パストラバーサル防御**: ファイル入出力やトレース取込において、`..` や無効なシンボリックリンクを含むパスはすべて拒絶されます。

---

## 4. 脆弱性の報告

セキュリティ上の脆弱性を発見された場合は、公開 Issue に投稿せず、リポジトリの Security Advisory または管理者の連絡先へ非公開でご報告ください。
